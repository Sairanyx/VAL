Val: Industrial Metaverse demo
==============================

1. Unzip this whole folder somewhere with a short path, such as Desktop or C:\demo.
2. Start it:
     Windows   double-click START-WINDOWS.bat. If Windows warns, choose More info, then Run anyway.
     Mac       right-click START-MAC.command, then Open, then Open again.
     Linux     run sh START-LINUX.sh
3. The first time, it sets itself up inside this folder. That needs internet and a minute or two.
   After that it needs no internet at all. The browser opens by itself.
4. In the browser, open Actions and press Demo for a guided tour, or look around yourself.

Use Chrome or Edge. Leave the black window open: closing it stops the demo.

Getting around: W A S D or the arrow keys walk, drag to look, V talks to Val, Esc goes back.

Nothing is installed outside this folder. Delete the folder to remove everything.
Changes you make last until the demo stops, and it starts as scanned each time.

If it looks slow, the browser may have no graphics acceleration: turn on "Use graphics acceleration"
in the browser's settings. If it doesn't start at all, demo.log says why, and the video shows it all.

Val answers from the records in the Excel pack without an AI model on this laptop, and speech
stays on this machine. The objects' links to records are procedural guesses, and marked with "?".
This data is Valmet's: please don't pass it on.
